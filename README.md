- 硬件：当前通过图示和推演说明；不将示例或纸面分析写成真实硬件实验。
- 编写方式：跟随实际教学增量更新，不预先生成全部章节。

建档日期：2026-10-10（Asia/Shanghai）。P021～P037当前引导范围累计完成、帮助历史保留。P037完整多字节函数引导后首次代码正确，参考入10.6，M09当前规划内容已覆盖，无待修改项。M07/I01课堂跳过，集中复习/I02待用户启动；资料覆盖不等于独立实现或硬件验证。

## 三、章节编写规则

对应模块正式开始后，才创建其章节；完成讲解、理解检查和必要纠正后，将确认正确的知识增量写入。

2026-10-18明确例外：用户要求M07不课堂学习但教材完整写出，因此该章可一次交付自学正文；不据此提前生成其他未来模块，也不把资料交付记学习/实验完成。

2026-10-18后续明确授权：用户要求跳过面试交互并写完M08，因此本章面试问答和自学参考完整交付；I01首问未作答并取消，不记模拟面试通过，也不自动开始集中复习/I02。

按实际需要组织以下内容：

1. 本章目标与前置知识。
2. 核心结构模型与解决的问题。
3. 核心概念、连接与时序。
4. 完整通信流程及简单示例。
5. 常见混淆、边界和故障诊断。
6. 参数、信号或流程速查。
7. 复习自测与资料入口。

- 示例优先展示“图示/代码 → 示例现象 → 关键步骤解释 → 观察结论 → 适用条件”。
- 波形、输出和代码应注明是示意、推演还是实际测量/运行结果。
- 具体电气参数、时序要求和地址约定需核对规范及目标器件手册，不把个别芯片行为写成通用结论。
- 不将尚未确认的猜测写成教材结论。
- 不记录个人分数、逐次练习历史或完整终端流水。
- 按2026-11-07教材整理反馈，以主题组织正文并合并重复说明；新增知识归入对应小节，自测题与答案集中编号，避免将逐次课堂过渡堆入正文。
- 按用户2026-10-21要求，代码章节在最开始统一列出该章结构体、宏和共用接口；新增定义同步补入。函数编写并检查正确后，在对应小节补全完整参考实现、参数/返回约定与必要说明，不提前替学习者完成尚未结束的引导题。
- 每组复习自测后必须提供与题号一一对应的参考答案；答案包含关键机制及必要边界，便于长期复习。后续新增题目时同步补充答案。
- 时序相关知识应配波形图，明确实际信号、位边界、采样点、时间轴与单位。图示必须标明是教学推演还是实际测量；不能只用文字或表格代替波形。当前图保存在 `图示/`，并嵌入相应正文。
- 章节创建后更新本目录的真实链接和覆盖状态。
- 拆分、合并章节或大幅改变目录层次前，先说明原因并取得确认。
